# Лабораторная работа № 1

## Сбор конфигурации macOS в формате JSON

### Цель работы

Научиться получать сведения о конфигурации операционной системы средствами Python и сохранять полученные данные в формате JSON.

### Задание

Написать на Python программу, которая:

1. Собирает основные сведения о конфигурации macOS.
2. Оформляет полученные данные в виде Python-словаря.
3. Сохраняет результат в файле формата JSON.

### Ограничения

- Для получения системных данных разрешено использовать модуль `os`.
- Для сохранения результа используется модуль `json`.
- Запрещено запускать готовые системные утилиты macOS, которые сами собирают конфигурацию системы.
- Программа не должна получать готовый результат через `subprocess` или `os.system()`.

### Используемые средства

- Python 3;
- `os` — получение данных о системе;
- `json` — преобразование данных в JSON и запись в файл.

Дополнительные библиотеки не требуются.

### Запуск

В терминале необходимо перейти в папку проекта и выполнить:

```bash
python3 main.py
```

### Результат работы

После запуска программы в папке проекта должен появиться JSON-файл с собранными сведениями о конфигурации macOS.
