# SCM — SysConfMac

## Лабораторная работа № 1

SCM — учебный проект для сбора и сохранения сведений о конфигурации операционной системы в формате JSON.

Проект планируется разделить на три части:

- `SysConfMac` — сбор конфигурации macOS;
- `SysConfWin` — сбор конфигурации Windows;
- `SysConfLinux` — сбор конфигурации Linux.

В первой лабораторной работе реализуется только `SysConfMac`.

### Цель работы

Научиться получать сведения о конфигурации macOS средствами Python, обрабатывать полученные значения и сохранять их в формате JSON.

### Задание

Написать на Python программу, которая:

1. Собирает основные сведения о macOS.
2. Сохраняет полученные значения в Python-словаре.
3. Переводит объём памяти и диска из байтов в гигабайты.
4. Записывает результат в файл `system_configuration.json`.

## Собираемые данные

Программа собирает:

- название системы;
- имя компьютера;
- версию и описание ядра;
- архитектуру процессора;
- количество логических ядер;
- общий объём оперативной памяти;
- общий и свободный объём основного диска.

## Как работает программа

1. `os.uname()` получает название системы, имя компьютера, версию ядра и архитектуру.
2. `os.cpu_count()` возвращает количество логических ядер процессора.
3. `os.sysconf()` получает размер и количество страниц оперативной памяти. Их произведение даёт общий объём памяти в байтах.
4. `os.statvfs("/")` получает сведения о корневой файловой системе и позволяет рассчитать общий и свободный объём диска.
5. Собранные значения помещаются в словарь `configuration`.
6. `json.dump()` записывает словарь в JSON-файл.

## Ограничения

- Для получения системных данных разрешено использовать модуль `os`.
- Для сохранения результата используется модуль `json`.
- Готовые системные утилиты macOS не запускаются.
- `subprocess` и `os.system()` не используются.


## Запуск

В терминале необходимо перейти в папку проекта и выполнить:

```bash
python3 main.py
```

После успешного запуска в текущей папке создаётся файл `system_configuration.json`.

## Ограничения текущей версии

Модуль `os` не возвращает модель Mac, точное название процессора и маркетинговую версию macOS. Поле `kernel_release` содержит версию ядра Darwin, а не версию macOS.
